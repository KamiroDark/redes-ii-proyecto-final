! =====================================================
! ACL 1 - Acceso administrativo solo por SSH desde la VLAN 40
! Aplicado igual en R1-PAMPLONA, R2-PAMPLONA y S3 - 2026-11-19
! =====================================================
configure terminal
ip domain-name pamplona.local
crypto key generate rsa modulus 2048
ip ssh version 2
username admin privilege 15 secret <CONTRASENA>
ip access-list standard ACCESO_ADMIN
 remark Solo la VLAN 40 (Admin) puede administrar el equipo
 permit 192.168.40.0 0.0.0.255
 deny any log
exit
line vty 0 4
 access-class ACCESO_ADMIN in
 login local
 transport input ssh
end
write memory
