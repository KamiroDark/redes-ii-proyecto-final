Arquitectura

Tres dominios, una sola red

Cada dominio funciona de forma independiente y luego se integra mediante redistribución controlada de rutas, para lograr comunicación total entre todas las redes internas.

DOMINIO 1 · RIP V2

Sede Pamplona

Red de usuarios y servicios con segmentación por VLAN, enrutamiento inter-VLAN y salida a Internet.

  • RIP v2 sin auto-summary y passive-interface
  • Router-on-a-stick con 4 subinterfaces 802.1Q
  • Switch multicapa con SVI y puerto enrutado
  • NAT/PAT hacia Internet en el router de borde
DOMINIO 2 · EIGRP

Red regional

Red corporativa de varias sedes interconectadas por enlaces punto a punto en un sistema autónomo propio.

  • Vecindades EIGRP validadas
  • Tabla de topología y sucesores factibles
  • Varias LAN de sede
  • Redistribución hacia RIP y OSPF
DOMINIO 3 · OSPF

Núcleo multimarca

Interoperabilidad entre plataformas de distintos fabricantes usando un estándar abierto.

  • Área 0 (backbone)
  • Vecindades OSPF y LSDB validadas
  • Equipos de diferentes plataformas
  • Interconexión con RIP y EIGRP

Seguridad

Diseñada para protegerse

Cada servicio expone solo lo necesario y cada decisión está documentada y justificada.

Implementación

Fases del proyecto

Primero cada dominio por separado; después la integración, el monitoreo y la automatización.

Fase 1 · Diseño

Topología, direccionamiento, VLANs y plan de servicios.

Fase 2 · Dominio RIP

VLANs, troncales, inter-VLAN, RIP v2, NAT, DHCP, DNS y servidor web.

Fase 3 · EIGRP y OSPF

Dominios independientes con vecindades verificadas.

Fase 4 · Integración

Redistribución entre protocolos, ruta por defecto controlada, EtherChannel y ACLs.

Fase 5 · Monitoreo y automatización

Zabbix, Grafana, n8n y bot de Telegram.
